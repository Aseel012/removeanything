# RemoveAnything AI

AI-powered background removal and Gemini Nano Banana watermark remover.

## Stack
- Flask 3 + Flask-CORS
- rembg (u2net) — background removal
- py-gemini-watermark-remover — watermark removal
- Firebase Authentication (Google Sign-In)
- Gunicorn

## Environment Variables Required
See `.env.example` for all required variables.
